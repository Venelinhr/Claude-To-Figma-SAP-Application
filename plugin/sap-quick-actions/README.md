# SAP Quick Actions

One-click SAP state changes on the selection. No model, no UI — under 0.2 s in Figma.

Install (once): Figma desktop → Plugins → Development → Import plugin from manifest →
`plugin/sap-quick-actions/manifest.json`.

Use: select a checkbox / switch / radio / button / card → ⌘/ → type the action
("Toggle", "Border → Selected", "Primary", "Cozy", "Side padding 16") → Enter.
⌘⌥P repeats the last action.

Actions: toggle on/off (Check Box `Check`, Switch `Checked`, Radio/Table Cell `Selected`),
selected/normal border (bound SAP variables), Button type, density, disabled/regular,
side padding 16/24/32. Selecting a frame applies variant actions to the SAP instances
inside it.
