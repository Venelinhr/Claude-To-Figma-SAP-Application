## The pipeline (build first, review after)
`node build/run.js <image | "text"> --file <KEY> [--ask]` — at t=0 in parallel: bridge + plugin check ‖ `front.js` (see.py OCR, gold match, door) → door again (+ `--baseline` geometry guard on resume) → asks triaged → layout-sim (position, overflow ×1 ×0.85 ×1.15) → STRUCT-SIM → logo crops →
`send.js` builds a frame `DRAFT — <job>` through the SAP Bridge plugin → `gates.js` (MATCH ≥ 90 · HYGIENE 0 · STRUCTURE 0 · EYE ≥ 95). Exit codes: 0 PASS · 1 door/sim OUT · 2 the model must decide (icons, text content, analysis failed) · 3 bridge down · 4 screen-changing ask (`--go`) · 5 `--ask` stop · 6 DRAFT or the 2-fix-round cap · 64 usage.
- An image job keeps a gold tree only if its simulated structure contains every reference box (else from zero). Text jobs: skeleton + `reskin.js` ops (content only). A NEW screen type gets its plan shown and approved first; Horizon Light always.
- Verbs (`route.js`): `tweak · show · flip · gold · fix`. Gold flywheel: `gold.js` (measured pass + door + `layout-sim --sizes` ≥ 90 %, never overwrites, `--demote`).
- Geometry (w h xy p g) of measured nodes is script-owned (`door.js --baseline`, `--allow "<node>"` re-opens one). Headless Claude builds stay banned.

## Lessons (kit facts and gotchas)
- 3× phone screenshots are read as 1×: crop the status bar, scale to the 2× export (390 → 780 px). Not automated.
- Kit inner text names (`tx` keys): Header `Title` · Object Attribute `Text` · Object Status `Text` (Semantic None/Information/Success/Warning/Error, Inverted, Large Design) · Object Number = its default text `956.00 EUR` · List Item `Title` + `✏️ Byline` · Progress Indicator `✏️ Text Value`, switch `Text`, `Value State`; its bar fill = width of the hugged text `✏️ Progress Bar` (34 chars ≈ 38 % of 358 px). Footer cannot hold a Button; Header cannot hold icon buttons.
- A kit switch that is ON by default can draw placeholder content that MATCH/HYGIENE do not see (List Item `Attachment`, `Separator`); door rule `DEFAULT_ON_PLACEHOLDER`.
- Kit icons: favorite share slim-arrow-down pushpin-on travel-itinerary suitcase decline media-forward thumb-up accept …; none for map pin / bus.
- The plugin placed new frames at the far right of the page (x ≈ 134,000); the user says it is fixed. A frame I built may be moved (position only).
- The permission classifier blocks agent writes to `.claude/commands/` and `SKILL.md`, loosening a gate, copying private memory into the repo, downloading a signed screenshot URL. The user runs those `cp` steps.
- Another Claude session shares the folder and moved HEAD to `v5` once: check `git branch --show-current` before every write.
