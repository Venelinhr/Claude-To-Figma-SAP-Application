## Audits that run before every build (plugin, Claude Code, in-Figma tools) — `build/content-audit.js`

## Lessons (2026-10-02)
- Every retry in a plugin job costs ≈ 10 s: give the model the exact layer names, op forms and slots (LAYOUT hints), and refuse bad content with the exact allowed value (audits).
- A fresh chat is the biggest speed gain for Claude Code runs (long chats re-send the whole context every turn).
- The pair token only passes in the `handleV4` section of `bridge/server.js`; the legacy section accepts only the CLI token (the log icon failed with "bad or missing token" until the route moved).
- A body can be read once: a route placed after `const b = await readBody(req)` must use `b`.
- A browser clipboard copy must run inside the click (user gesture); prefetch the data on render.
- The permission classifier blocks weakening a safety hook and `settings.local.json` edits; the user adds those rules. `rm -rf` triggers the fact hook again — avoid it.
- Plugin frames before the audits had swapped filter controls (Delivery Date on a Select, Status on the date picker) and random red / orange icons next to quantities; fixed by FILTER and NOISE.
