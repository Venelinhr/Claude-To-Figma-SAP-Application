User rule (2026-10-05): for the best view of a Make app, open it in Make **Preview mode → open in full screen, without the chat section**.

**Why:** with the chat panel open, the app is cropped and the clone loses width and parts.
**How to apply:** when I read or clone a Make link (CDP reading, screenshots, make-verify), use the full-screen preview of the app itself, not the editor. Never crop the editor. Related: [[make-engine-sync]].
